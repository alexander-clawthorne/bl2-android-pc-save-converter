BL2 Save Converter

Borderlands 2 saves: Wicked's Android port (v1.7) ↔ PC (Steam)

● Runs in your browser. Files are never uploaded.

How to

  1. Back up the save folder on the device you're copying to.
  2. Drop one or more saves. The direction is detected automatically.
  3. For characters, choose a slot ID no other character on that device uses.
  4. Download, then copy the file into the target save folder.

Slot IDs matter

Each character stores its own slot number, and the game saves back to the file with that number. If two characters share a slot, playing one overwrites the other.

Pick an unused number, ideally 1–9. The file is named to match (slot 6 → Save0006.sav).

Where saves live

PC (Steam):
Documents\My Games\Borderlands 2\WillowGame\SaveData\<Steam ID>\

If Steam Cloud reports a conflict on the next launch, choose the local files.

Profiles (profile.bin / Player1) hold badass rank, golden keys and settings. Replacing one overwrites that device's progress.
